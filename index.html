★ 일반동사의 과거형 만드는 법

🔊 영어 단어를 클릭하면 미국식 원어민 발음을 들을 수 있습니다.
규칙
변화		 대부분의 동사 동사원형 + -ed
watched(왓치트) talked(토크트) listened(리슨드) walked(워크트) wanted(원티드) started(스타티드) ended(엔디드) rained(레인드)
[자음 + -e]로 끝나는 동사 동사원형 + -d
lived(리브드) moved(무브드) liked(라이크트) loved(러브드) smiled(스마일드) danced(댄스트) invited(인바이티드) changed(체인지드)
[자음 + -y]로 끝나는 동사 y → i로 고치고
+ -ed
cry(크라이) → cried(크라이드)
study(스터디) → studied(스터디드)
try(트라이) → tried(트라이드)
worry(워리) → worried(워리드)
[단모음 + 단자음]으로 끝나는 동사 자음은 한 번 더 쓰고
+ -ed
stop(스탑) → stopped(스탑트)
plan(플랜) → planned(플랜드)
chat(챗) → chatted(채티드)
drop(드랍) → dropped(드랍트)
